# Plan: KAN-280 — Patch seam scaffold (vegaEmbed patch callback)

**Phase:** Labels v2 (compile-then-patch exploration)
**Jira:** KAN-280
**Depends on:** none (first story in KAN-279 epic)

## Overview

Add a no-op `patch` callback to the `vegaEmbed` call in `shelves/render/to_html.py`. This is the foundation for the compile-then-patch labels architecture: Vega-Lite compiles down to Vega, and the `patch` function receives the compiled Vega spec before rendering. Later stories (KAN-282+) will use this seam to inject label layers.

This story proves the seam works without changing any label or translator logic. Charts must render identically to before.

## Implementation Details

### The exact HTML change

The current vegaEmbed call:

```js
vegaEmbed('#chart', spec, {
  renderer: 'canvas',
  actions: { export: true, source: true, compiled: false, editor: true }
}).catch(console.error);
```

Becomes:

```js
function charterPatch(vgSpec) {
  const labels = vgSpec.usermeta?.charter?.labels;
  if (!labels || labels.length === 0) {
    return vgSpec;
  }
  // KAN-282+ will add label layer injection here.
  return vgSpec;
}

vegaEmbed('#chart', spec, {
  renderer: 'canvas',
  patch: charterPatch,
  actions: { export: true, source: true, compiled: false, editor: true }
}).catch(console.error);
```

**Why structure it this way:**
- Named function (not inline arrow) so later stories can add logic cleanly
- Already checks for `usermeta.charter.labels` and short-circuits — this avoids any runtime cost on charts without labels
- The `labels` guard means this is truly a no-op today but the structure is ready for KAN-282

**Note on f-string escaping:** The function body uses `vgSpec.usermeta?.charter?.labels` which contains no Python f-string special characters. The existing `{{` / `}}` escaping pattern in the template handles JS braces. No additional escaping needed.

## Implementation Notes

- **Only `to_html.py` changes.** Do not touch `labels.py`, `translate.py`, or any pattern module.
- The `charterPatch` function is defined inside the `<script>` block of the HTML template. It is not a separate `.js` file (yet — KAN-286 may extract it if it grows beyond ~80 lines).
- The dev server (`shelves/cli/dev.py`) calls `render_html()` — so the patch seam is automatically active in dev mode. No dev server changes needed.
